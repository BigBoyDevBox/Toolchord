# Toolchord

Toolchord is a proposed native macOS palette for everyday developer tools. Open it from the app you’re working in, paste a value or choose a command, then preview, copy, and return to your work.

The first release covers seven offline tools for JSON, XML, Base64, URLs, JWTs, timestamps, and UUIDs. XML support starts with formatting and well-formedness checks.

Start with the [product plan and design](docs/product-plan.md) for the panel layouts, keyboard behavior, first release scope, and implementation milestones.

- [Shortcut UX](docs/shortcut-ux.md) describes search, paste, and copy behavior and links to the browser design study.
- [Implementation contracts](docs/implementation-contracts.md) define copy results, format rules, fixtures, and native panel checks.
- [Research and tool priorities](docs/research.md) compare existing tools and outline what to try after the first release.
